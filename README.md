### 🌟 Acerca del Proyecto
Esta presentación interactiva fue desarrollada para exponer y validar pedagógicamente el proyecto **Code Quest**, una herramienta de desarrollo web interactiva estilo RPG diseñada para fortalecer la lógica de programación y los fundamentos de Java en estudiantes universitarios.

#### Características Destacadas de la Presentación:
1. **100% Código y Sprites Auténticos:** Cero imágenes estáticas o mockups generados por IA; utiliza el renderizado en tiempo real del motor del videojuego.
2. **Banda Sonora y Motor de Audio Oficial:** Reproducción fiel de los temas en MP3 de Bytevalia (`mapa.mp3` y pistas de combate `jefe1.mp3` a `jefe20.mp3`) con síntesis de sonido procedural para cortes, pociones y victorias.
3. **Arena de Combate Interactiva (Slide 8):** Simulación dinámica con sprites de ataque reales (`jugador_ataque_1`, `2`, `3`), impactos visuales y retroalimentación técnica.
4. **Vitrina de 20 Medallas Coleccionables (Slide 9):** Muestra el sistema de logros y gestión de la mochila de aventura con pociones curativas y llaves.
5. **Accesibilidad Móvil y Salón de la Fama (Slide 10):** Presentación del D-Pad virtual táctil y de la persistencia de clasificaciones en la nube.
6. **Simulador Jugable de Bytevalia (Slide 11):** Escenario espacioso en HTML5 Canvas con movimiento fluido del héroe, recolección de tesoros y encuentro interactivo con el Duende de la Sintaxis.
7. **Cierre Institucional con Código QR (Slide 12):** Código QR interactivo que redirige al juego desplegado en producción en Vercel.

### 🚀 Cómo Ejecutar Localmente

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/LuisChvzzz/Presentacion_CodeQuest.git
   cd Presentacion_CodeQuest
   ```

2. **Iniciar un servidor local (por ejemplo con Python):**
   ```bash
   python3 -m http.server 8089
   ```

3. **Abrir en el navegador:**
   Ingresa a `http://localhost:8089`

### 🎮 Controles de la Presentación
- **Avanzar Diapositiva:** `→`, `Espacio`, `PgDn` o botón "Siguiente"
- **Retroceder Diapositiva:** `←`, `Backspace`, `PgUp` o botón "Anterior"
- **Pantalla Completa:** Tecla `F`
- **Notas del Orador:** Tecla `N`
- **Vista de Mosaico (Overview):** Tecla `O`
- **Música:** Botón `🎵 Música` en el encabezado
- **Cronómetro:** Botones `▶` / `↺` en la barra superior
