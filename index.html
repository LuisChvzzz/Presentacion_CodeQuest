Visión General

¿Qué es este proyecto?

Una plataforma educativa web que convierte el estudio riguroso de Java en una travesía RPG accesible.

Plataforma Web Interactiva Estilo RPG

Diseñada específicamente para estudiantes universitarios que inician en Java. Ofrece un mundo 2D de exploración donde cada sendero conduce a un reto de programación.

Videojuegos + Aprendizaje Técnico

Combina mecánicas tradicionales de rol (combates por turnos, cofres de tesoro, llaves de mazmorras y medallas) con desafíos de lógica y conceptos fundamentales del lenguaje.

Retos Dinámicos y Feedback Formativo

El código no se memoriza, se comprende: los aciertos permiten avanzar y derrotar a los jefes, mientras que los fallos activan la explicación del Sabio para aprender sin frustración.

Fundamento & Motivación

El Origen del Proyecto

¿De dónde surgió la necesidad de crear Code Quest en la Universidad Veracruzana?

El Método Tradicional

La Barrera de la Sintaxis en Consola
  • Sintaxis Estricta y Críptica: La transición a Java exige dominar tipos primitivos, mayúsculas y minúsculas exactas y el cierre con punto y coma (;) desde el primer día.
  • Falta de Retroalimentación Gráfica: Los ejercicios en terminal y consola negra no transmiten avance visual ni motivan al alumno que recién descubre la programación.
  • Curva de Frustración Temprana: Al enfrentarse a errores de compilación sin contexto amigable, muchos estudiantes pierden el interés o abandonan la materia.
"El estudiante novel a menudo confunde un error de sintaxis elemental con una falta de aptitud para la programación."

La Solución: Code Quest

Gamificación Activa en el Reino de Java
  • El Compilador como Oponente: La regla de Java se personifica en guardianes medievales. Resolver el error de sintaxis es dar un golpe certero de espada.
  • Refuerzo Cognitivo Positivo: Coleccionar 20 medallas de oro, abrir cofres y escuchar música de victoria genera estímulos de logro inmediato en el alumno.
  • Inclusión y Cero Barreras Técnicas: Al ser 100% web, el estudiante no necesita configurar entornos pesados; abre su navegador en PC o móvil y practica de inmediato.
"Aprender Java a través de un juego devuelve la curiosidad y el sentido de logro al proceso de programar."

Misión Educativa

¿Cuál es nuestro Propósito?

Tres pilares formativos diseñados para transformar la enseñanza de la computación.

1. Fortalecer Fundamentos

Consolidar las bases críticas que todo programador requiere: declaración de variables, operadores aritméticos, bifurcaciones if/else, bucles y programación orientada a objetos.

Rigor Conceptual

2. Aprendizaje Sin Presión

Cambiar el paradigma del castigo por el error formativo. Cuando el estudiante se equivoca en batalla, el Sabio le explica el motivo exacto, reforzando el concepto sin penalizar su motivación.

Pedagogía Humanista

3. Accesibilidad Universal

Garantizar que cualquier estudiante, independientemente de la potencia de su equipo, pueda ejecutar el juego fluidamente desde cualquier navegador web moderno sin descargas ni configuraciones.

Evaluación Formativa

Desafío de Código: Preguntas Fundamentales

Preguntas prácticas directas con retroalimentación instantánea y sabiduría explicativa.

1. Sintaxis Básica (Punto y Coma)

Terminación obligatoria de cada sentencia de código ejecutable.

2. Tipos de Datos (Enteros)

Tipo primitivo int para almacenamiento numérico sin decimales.

3. Salida por Pantalla (Print)

Uso de System.out.println() para visualización en consola.

4. Decisiones Lógicas (Condicional if)

Estructura if para evaluar expresiones booleanas de verdadero o falso.

⚔️ Desafío de Java #1 Básico & Educativo

¿Con qué símbolo o carácter debe terminar obligatoriamente cada instrucción en Java?

Consejo Pedagógico del Sabio:

¡Elige una opción para atacar al guardián! En Java, el compilador requiere un delimitador estricto al finalizar cada sentencia.
